Drop the original files from the attachments into this folder using the exact
file names below. They are picked up automatically at build time (any of
`.png .jpg .jpeg .webp`) and inlined into the single-file build. Until a file is
present, the matching slot on the site renders a clearly labelled
"photo not supplied" frame — nothing is redrawn or substituted.
