## The flagship, at a glance

The GUNI GUNI proposal repo is our working example of the strategy:

```
guniguni/  →  a proposal you can run
├── README.md                 the pitch: stack, code tree, architecture, roadmap
├── docs/PROPOSAL.md          scope · phases · acceptance criteria
├── docs/GITHUB-AS-PROPOSAL.md  the strategy behind proposing on GitHub
├── src/                      React 19 + TS + Tailwind — site, ordering, staff, admin, AI
├── server/                   zero-dependency Node API (runs anywhere)
└── supabase/                 Postgres + RLS + Edge Functions alternative backend
```

**75 menu items · private costing & recipes · server-side price validation · AI guest host & staff ops
console · three storage modes (Supabase / Node / offline demo).**
Read it → [github.com/merqatodigital/guniguni](https://github.com/merqatodigital/guniguni)
